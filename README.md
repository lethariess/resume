## 🚀 Инструкция по публикации на GitHub Pages

1. **Создайте репозиторий на GitHub:**
   - Перейдите на [github.com/new](https://github.com/new)
   - Назовите репозиторий `resume` (или `<ваш-логин>.github.io`)
   - Сделайте репозиторий **Public** (публичным).

2. **Загрузите файлы в репозиторий:**
   ```bash
   git init
   git add .
   git commit -m "feat: Initial commit of interactive resume"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/resume.git
   git push -u origin main
   ```

3. **Включите GitHub Pages:**
   - В репозитории откройте вкладку **Settings** -> раздел **Pages** (в левом меню).
   - В блоке **Build and deployment** выберите:
     - **Source**: `Deploy from a branch`
     - **Branch**: `main` / `/ (root)`
   - Нажмите **Save**.
   - Через 1–2 минуты страница станет доступна по публичной ссылке:
     `https://<ваш-логин>.github.io/resume/`
