REST API / Бронирование

Система онлайн-бронирования услуг (Booking Platform API)

Отказоустойчивый RESTful бэкенд-сервис для автоматизации предварительной записи клиентов на услуги компании. Сервис управляет слотами времени, предотвращает конфликты одновременного бронирования (double-booking) через транзакции с блокировками SELECT FOR UPDATE, поддерживает генерацию чеков и email-уведомления.

Цель: Автоматизация приема заявок, сокращение времени оформления с 30 до 2 минут.
Результат: Пропускная способность 450 rps, 99.8% uptime, покрытие автотестами > 85%.

Микросервисы / Асинхронные очереди

Сервис распределенных фоновых задач и нотификаций

Микросервисный конвейер обработки ресурсоемких задач: генерации сводных PDF-отчетов по расписанию, пакетной рассылки Telegram/Email-уведомлений и синхронизации данных со сторонними API через брокер сообщений Redis. Архитектура сервиса бронирования (FastAPI + PostgreSQL + Redis)

Ключевые архитектурные решения:

  • Асинхронность (async/await): обработка до 450 одновременных запросов в секунду без блокировки потоков.
  • Предотвращение коллизий (Race Conditions): транзакции с SELECT ... FOR UPDATE гарантируют, что временной слот не будет забронирован двумя клиентами одновременно.
  • Кэширование в Redis: снижает нагрузку на реляционную базу данных на 70% при частых запросах каталога услуг.

Конвейер обработки фоновых задач (Celery + Redis Broker)

Асинхронные задачи изолированы в воркерах: при сбоях сети используется Dead Letter Queue (DLQ) и автоматические повторные попытки с экспоненциальной задержкой.

Фрагмент конфигурации docker-compose.yml

version: '3.8'

services:
  web:
    build: .
    command: uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 4
    volumes:
      - .:/app
    ports:
      - "8000:8000"
    environment:
      - DATABASE_URL=postgresql+asyncpg://postgres:secret@db:5432/booking_db
      - REDIS_URL=redis://redis:6379/0
    depends_on:
      - db
      - redis

  worker:
    build: .
    command: celery -A app.core.celery_app worker --loglevel=info -c 4
    depends_on:
      - redis
      - db

  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"

  db:
    image: postgres:15-alpine
    environment:
      - POSTGRES_DB=booking_db
      - POSTGRES_PASSWORD=secret
    volumes:
      - pgdata:/var/lib/postgresql/data

volumes:
  pgdata:
